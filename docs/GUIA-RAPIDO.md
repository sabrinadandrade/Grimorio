# ☾ Guia rápido do Grimório ☽

Um resumo de uma página: o que é, o que é importante saber e como usar no **iPhone** e no **Android**.
Para o passo a passo completo, com imagens, veja o [tutorial](TUTORIAL.md).

- **Site:** <https://sabrinadandrade.github.io/Grimorio/>
- **App Android:** <https://github.com/sabrinadandrade/Grimorio/releases/latest>

## 🔮 O que é

Um planner fofo (estética kawaii anos 90, com toque de bruxinha 🎃) para **estudos e para a vida**, com pets que torcem por você.

- **Estudos:** importe provas e matérias da sua faculdade (colando o texto do portal, ou com `.csv`, `.ics`, `.json`) e ele monta o plano até cada prova. Tem tarot de estudos (flashcards), "o que cai" e calendário lunar.
- **Atividades da vida:** estudos, rotina, casa, pets, filhos, trabalho, compromissos e saúde. Cada uma pode ter prioridade (🔥 ⭐ 🌙), repetir na semana, ter subtarefas e lembrete com um pet aparecendo na tela.
- **Para manter o foco:** visão da semana, sequência de dias 🔥, conquistas 🏆 e um bichinho virtual com timer de foco (dá para aumentar e diminuir).
- **Do seu jeito:** 14 espécies de pets com cores e acessórios, 7 temas de cores, formatos do bichinho, pronome (ele / ela / elu), português e inglês.
- **Menu:** no celular, é lateral (☰); no computador, fica fixo no topo.

## ⭐ Pontos importantes

### 🔒 Seus dados ficam só no seu aparelho
- O Grimório **não tem servidor, banco de dados nem login**. Nada é enviado para a internet.
- Ele guarda duas cópias dentro do aparelho e se recupera sozinho se uma sumir.

### ⚠️ Cuidados
- **Cada aparelho tem o seu grimório.** Eles **não se sincronizam sozinhos**. Dica: escolha um **aparelho principal** e passe os dados pelo arquivo `.grimorio` quando quiser (veja abaixo).
- Se você **limpar os dados do navegador** ou **desinstalar o app**, os dados vão junto. **Faça backup de vez em quando.** O Grimório te lembra depois de 7 dias.

### 🔐 Backup trancado com senha
- Em **Importar / conectar → passar_aparelho.exe → 🔐 Exportar backup criptografado**, você gera um arquivo `.grimorio` que **só abre com a sua senha** (criptografia AES-256).
- Serve para guardar uma cópia ou levar seus dados para outro aparelho.
- **Esqueceu a senha?** Esse arquivo não abre de jeito nenhum (nem a gente consegue). Anote a senha num lugar seguro.

### 📲 Passar para outro aparelho
1. **No aparelho onde estão seus dados:** **🔐 Exportar backup criptografado** e crie uma senha.
2. Leve o arquivo `.grimorio` para o outro aparelho: AirDrop, cabo, pendrive… Mesmo que passe por algum app, ele está trancado.
3. **No outro aparelho:** **Importar / conectar → 📂 Importar arquivo** → escolha o arquivo e digite a senha.

## 🍎 Como usar no iPhone

1. Abra **<https://sabrinadandrade.github.io/Grimorio/>** no **Safari**. Precisa ser o Safari.
2. Toque em **Compartilhar ⬆️ → Adicionar à Tela de Início → Adicionar**.
3. Abra sempre **pelo ícone**. Ele vira um app em tela cheia e funciona até sem internet.
4. Para trazer dados de outro aparelho, siga o [passar para outro aparelho](#-passar-para-outro-aparelho). No iPhone, salve o `.grimorio` no app **Arquivos** (ou receba por AirDrop) e escolha ele em **📂 Importar arquivo**.

> 🔔 No iPhone, os lembretes aparecem com o seu pet **quando o Grimório está aberto**. Com o app fechado, não chega notificação. Abra o app algumas vezes por dia 💜

## 🤖 Como usar no Android

1. Baixe o **Grimorio.apk** em **<https://github.com/sabrinadandrade/Grimorio/releases/latest>**.
2. Toque no arquivo baixado. Na primeira vez, o Android avisa que o app não veio da Play Store: toque em **Configurações → Permitir desta fonte**, volte e toque em **Instalar**.
3. Abra o app e **permita as notificações**. Os lembretes chegam **mesmo com o app fechado** 🔔
4. Para trazer dados de outro aparelho, use o [passar para outro aparelho](#-passar-para-outro-aparelho).
5. **Para atualizar:** baixe o APK de novo pelo mesmo link e instale por cima. Seus dados continuam lá (por garantia, faça um backup antes).

> Também dá para usar pelo site no **Chrome**: menu ⋮ → **Adicionar à tela inicial**. Mas os avisos com o app fechado só funcionam no **app (APK)**.

---

## 💻 Como usar no computador

Abra **<https://sabrinadandrade.github.io/Grimorio/>** no Chrome, Edge, Opera ou outro navegador. No Chrome e no Edge, dá para **instalar** como app (ícone ➕ na barra de endereço) e ligar o **💾 Backup automático**, que salva um arquivo no seu computador sempre que algo muda.
